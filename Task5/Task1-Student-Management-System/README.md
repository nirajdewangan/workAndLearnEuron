# Student Management System

A beginner-friendly Python project demonstrating Object-Oriented Programming (OOP).

## Concepts Used

- Class and objects
- `__init__` constructor
- Instance attributes
- Instance methods
- Class variable
- `@classmethod`
- List of objects
- Basic validation

## Features

- Store a student's name, email, student ID, course, and marks
- Display complete student details
- Update an individual mark
- Calculate average marks
- Track the total number of students created

## Project Structure

```text
student-management-system/
├── student_management.py
├── README.md
└── sample_output.txt
```

## How to Run

1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

```bash
python student_management.py
```

On some systems, use:

```bash
python3 student_management.py
```

## Main Methods

- `display_details()` displays a student's information.
- `update_marks(subject_index, new_mark)` changes a mark.
- `calculate_average()` returns average marks.
- `get_total_students()` returns the number of student objects created.
