# Bank Account System

A beginner-friendly banking application built with Python Object-Oriented Programming.

## Requirements Covered

- `BankAccount` class
- Account holder name, account number, and balance
- `deposit()` method
- `withdraw()` method
- `check_balance()` method
- `display_account_details()` method
- Class variable for the bank name
- Class method to change the bank name for every account
- Validation to prevent withdrawing more than the available balance
- Bonus: total number of bank accounts created

## Additional Validation

- Opening balance cannot be negative
- Deposit amount must be greater than zero
- Withdrawal amount must be greater than zero
- Bank name cannot be empty

## How to Run

Open a terminal in this folder and run:

```bash
python bank_account.py
```

On some systems, use:

```bash
python3 bank_account.py
```
