# Build Your Developer Profile Using Variables

## About the Project

This is a beginner Python project created to practice variables and basic Python data types.

The program stores my developer profile information in different variables and prints both the values and their data types.

## Concepts Used

* String (`str`)
* Integer (`int`)
* Float (`float`)
* Boolean (`bool`)
* `print()`
* `type()`
