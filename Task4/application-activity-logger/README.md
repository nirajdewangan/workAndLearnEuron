# Application Activity Logger

A menu-driven Python command-line application created to demonstrate
Python logging and exception handling.

## Features

1. Login
2. Calculate
3. Read a File
4. Write a File
5. Logout

The application generates logs at:

- DEBUG
- INFO
- WARNING
- ERROR
- CRITICAL

## Log Files

Logs are stored inside:

```text
logs/
├── application.log
└── error.log
