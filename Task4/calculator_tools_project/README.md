# Calculator Tools Python Package

A reusable Python package demonstrating functions, modules,
packages, imports, exception handling, and custom exceptions.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Average calculation
- Celsius to Fahrenheit conversion
- Fahrenheit to Celsius conversion
- Length conversion
- Error handling
- Custom InvalidOperationError exception

## Project Structure

calculator_tools/
- __init__.py
- arithmetic.py
- statistics.py
- converter.py
- exceptions.py

main.py

## Run Project

```bash
python main.py
